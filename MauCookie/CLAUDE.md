# MauCookie — guide for future work

Complete reference for the MauCookie addon. Read it before changing anything. Target client, install loop, syntax check (node + luaparse, `tools/check.js`) and the Blizzard source branch are the same as for MauUndercut (`../MauUndercut/CLAUDE.md` sections 2 and 3); window, options, key binding and compartment follow the MauPlinko pattern (`../MauPlinko/CLAUDE.md` section 6 lists the client facts).

## 1. What it is

Cookie Clicker (Orteil / DashNet, version 2.052) ported to the game, for the user and one friend ("1 on 1 with Cookie Clicker" is the stated goal). 0.5.0 (2026-10-10) is a full rebuild: the game data is **generated** from the original's `main.js` (section 3), the rules are **ported function by function** from it (section 4), and the window follows the original's three-column layout with the original's art (sections 5 and 6). `/mck` toggles the window. The save is account wide (`MauCookieDB.save`). **No offline production**: the user explicitly does not want cookies for time logged out; the bakery runs only while logged in, window open or not, and the timers (research, pledges, seasons, buffs) count bakery time. Sugar lumps and the Century egg count real time like the original (lumps that fell while away are harvested on login). The "Javascript console" is one of the original's buildings, not a console; the user once asked to remove it and accepted the explanation.

## 3. Data pipeline

`tools/extract.js` runs the original's `main.js` (not in the repository; download `https://orteil.dashnet.org/cookieclicker/main.js` and `loc/EN.js` into `../cc-source/` next to `tools/`) in a Node `vm` sandbox with a Proxy standing in for the DOM, until `Game.Init()` completes, then dumps tiers, buildings, upgrades, achievements, `UnlockAt` and the misc tables to `cc-data.json`. `tools/gen-lua.js` writes the four `Data_*.lua` files from it. Lessons: do not inject host intrinsics (`Array`, `Object`) into the sandbox (the original checks `params.constructor!==Array` and descriptions came out as "+undefined%"); `Game.YouCustomizer.render();` is stripped from the source; missing globals are auto-defined by retrying; errors inside `Game.Loop/Draw` after Init are tolerated. Regenerate with `node extract.js && node gen-lua.js` from `tools/` (needs `npm i acorn` only for the old parsing attempt; the vm route needs nothing).

## 4. Rules

### 4.1 Save (`MauCookieDB.save`, `v = 2`)

`cookies`, `earned` (this run), `reset` (cookies forfeited by ascending; all time = reset + earned), `clicks`, `handmade`, `goldenClicks`, `goldenClicksLocal`, `missedGolden`, `reindeerClicked`, `bld[name] = { n, bought, highest, free, total, level }`, `up[name]` (bought), `unl[name]` (unlocked), `ach[name]`, `buffs` (list), `vault[name]`, `perma[1..5]` (upgrade names), `prestige`, `chips`, `chipsSpent`, `resets`, `startDate` (run, server time), `fullDate`, `playTime`, `runTime` (bakery seconds), `pledges`, `pledgeT`, `elderWrath`, `nextResearch`, `researchT`, `season` ("" or key), `seasonT`, `seasonUses`, `wrinklers`, `wrinklersPopped`, `cookiesSucked`, `santaLevel`, `dragonLevel`, `dragonAura`, `dragonAura2`, `lumps` (-1 before they start), `lumpsTotal`, `lumpT` (real time), `lumpRefill`, `lumpType`, `milkType`, `bgType`, `chimeType`, `fortuneGC`, `fortuneCPS`, `tickerClicks`, `onAscend`, `ascensionMode` (always 0 for now), `cpsHighest`, `sold`, `minigames`. Everything is keyed by the original's names. `MigrateSave` converts a 0.4.0 save (`baked`, `buildings[oldId]`, `upgrades[oldId]`...): buildings, mappable upgrades and achievements carry over, prestige is recomputed with the original's formula and every chip is refunded (the old heavenly upgrades used another curve); `save.migrated` makes `Game:Start` rebuild the unlock state; the old save is kept as `MauCookieDB.save_v1`.

### 4.2 Ported formulas (main.js function in brackets)

- Production (`Game.CalculateGains`): prestige x heavenly multiplier, cookie upgrades (`power`, functions for the heart biscuits, Birthday cookie, Sugar crystal cookies), research and seasonal multipliers, Santa's legacy, milk = achievements / 25 (normal pool only), kittens, building cps x (1 + level/100) x god multipliers, "egg" +9, eggs, Century egg (real days), Sugar baking, Radiant Appetite, CpS achievements, Dragon's Fortune per golden cookie on screen, wrinkler suck rate, Elder Covenant 0.95, Golden switch 1.5 (+0.1 per golden upgrade with Residual luck), Shimmering veil, then buffs (`multCpS`). `Game.cps`, `unbuffedCps`, `rawCps`, `globalMult`, `cpsBy[name] = { each, total }`, `milkProgress`, `cpsSucked`, `mouse`.
- Building cps (each `Game.Object`'s `cps`): Cursor `ComputeCps(0.1, tiers, thousandFingersAdd x non-cursor buildings)`, Grandma with the synergy doublings, Bingo x4, Ritual rolling pins, Naughty list, Elderwort, Cat ladies, One mind / Communal / Elder Pact adds, Elder Battalion; everything else `baseCps x GetTieredCpsMult` (x2 per tier, unshackle extras, synergies +5% / +0.1%, fortune 1.07, grandma synergy).
- Click (`Game.mouseCps`), building prices (`getPrice`, `getSumPrice`, `getReverseSumPrice`, `modifyBuildingPrice`, sell 0.25 x Earth Shatterer), upgrade prices (`Upgrade.getPrice` plus every `priceFunc` by name in `UpgradeBasePrice`: Elder Pledge, Golden switch, Shimmering veil, Fortune #100-#102, garden drops and Wrinkler ambergris (minutes of CpS), dragon drops, Santa drops, eggs, season triggers, Chimera on synergies).
- Buying (`Upgrade.buy`, toggles via `NS.TOGGLE_INTO`, lumps via `SpendLumps`), the buy functions (`OnUpgradeBought`: research chain, Elder Pledge / Covenant / Revoke, A festive hat, Chocolate egg, Sugar frenzy, Season switcher, season triggers), `RebuildUpgrades` (`UpgradesInStore`: toggles sorted by order, the rest by price; owned Elder Pledge and season triggers stay listed with timers).
- Unlocks: building buy functions (`OnBuildingBought`, `UnlockTiered`), the five-second block (`CheckUnlocks`: UnlockAt, switches, Legacy chain, bank achievements, centennials, hand-made, buildings/upgrades owned, kittens, grandma synergies, Bingo, pledges, production achievements, eggs, fortunes, lumps), milk ranks.
- Grandmapocalypse (`UpdateGrandmapocalypse`: wrath 0-3, pledge timer, Elder Pact unlocks the pledge), wrinklers (`UpdateWrinklers`, pop values x1.1 x1.05 Sacrilegious x Dragon Guts x3 shiny x1.05 Wrinklerspawn, Halloween drops, ambergris 1/10000).
- Golden cookies (`shimmerTypes.golden`: wrath chance by elderWrath, duration 13 s with the luck upgrades and 0.95 per extra cookie, chains at max(2, 10/chain) s, spawn 5-15 min with every modifier, the effect list with its probabilities, `effectDurMod`, payouts; `blab` 1/10000), reindeer (4 s, 3-5 min, pays max(25, 60 s of CpS)), storm drops (50% per frame in the original, capped at 40 on screen here), eggs (`DropEgg`).
- Lumps (`computeLumpTimes`, `clickLump`, `harvestLumps`, `computeLumpType`, 15 min refill), Santa (`UpgradeSanta`), dragon (`dragonLevels`: 1M x 2^n cookies, 100 of each building per aura, 50 of everything for the Dragon cookie, 200 for the second aura; `auraMult` with Reality Bending), fortunes (2% / 4% per ticker line).
- Ascension (`HowMuchPrestige` cube root of cookies / 1e12, `EarnHeavenlyChips`, `Reset`: forfeit achievements, Keepsakes, O Fortuna, permanent slots, Starter kit / kitchen, Season switcher), tree (`BuildAscendTree`: every parent bought; ghosted children of buyable ones), permanent slots (`AssignPermanentSlot`: bought + unlocked, pool "" or cookie).

Deliberate deviations: timers on bakery time (see section 1), including the garden ticks, the market ticks, pantheon swaps and the soil cooldown; heralds = 0 (there is no server); Cookie-dunker is won when milk reaches 100%; Speed baking uses bakery time of the run; "Born again" and "Trigger finger" ascension modes are not offered; debug upgrades are never unlocked; the Dungeon minigame does not exist in the original either; the stock market's "opportunities" are commented out in the original and absent here; pantheon spirits are slotted through a prompt instead of drag and drop.

## 5. Window (`UI*.lua`)

1000 x 640, title bar 22 px (drag, close), scaled by the `scale` setting. Left 300 px: bakery name (`<player>'s bakery`), counter band at 10% (cookies, per second, red when wrinklers eat), prestige line, the 256 px cookie at 40% with two rotating shines and a shadow, buffs as 36 px crates with the `pieFill` pie timer at the top right, wrinklers as 230 px square buttons rotated towards the cookie at distance 128 x (2 - close) and angle id / max x 360, milk at the bottom (height 35% x milkProgress, eased, texcoords scrolling), Santa / dragon tabs at the bottom left with a panel (evolve / train, cost, aura crates). Middle 382 px: the menu buttons (Options, Stats, Info, Legacy, Guild) with the sugar lump under Stats, the 64 px ticker (fortunes shown with the fortune icon, click to claim), then the building rows (`UI_Rows`: 128 px, background tile, sprites placed with the original's formula and a seeded LCG for the jitter, grandma types picked at random, frame sheets for Cortex baker and Idleverse) or a menu (`UI_Menus`, scrolling). Right 318 px (`UI_Store`): sections on the `panelHorizontal` strip (Upgrades with the Buy all button when Inspired checklist is owned, Switches, Research, Vault), 48 px crates in 60 px `upgradeFrame` frames (five per row, dimmed and desaturated when unaffordable, hover frame), the bulk buttons (Buy / Sell, 1 / 10 / 100 / all), products 300 x 64 on the store tile with the buildings-sheet icon (column 1 greyed, 2 / 3 on Business day, the angry grandma icons by wrath), title, price with the money icon, owned count, level and level-up button when lumps exist, a minigame button when the building has one and level >= 1. Locked buildings show "???" and only the first two locked ones are listed. Shimmers are buttons in a layer over the left and middle (golden / wrath, seasonal sheets, wreaths at Christmas, reindeer crossing left to right). Notes stack at the bottom of the middle (click to dismiss). `UI:Prompt(title, text, buttons, grid)` is the in-window dialog (confirmations, selectors, aura and permanent slot pickers). The ascension screen (`UI_Ascend`) covers the window: star background, heaven rings, pannable (drag) and zoomable (wheel) tree with lines between parents and children (LibGraph's rotated-texcoord line), chips and prestige at the top, Ascend (with the original's confirmation text) or Reincarnate at the bottom; the Legacy button opens it as a preview.

Refresh: `UI:Refresh(force)` at 10 Hz and on every `Game:Changed()`; the store is rebuilt only when `Game.storeDirty`; rows re-lay out when a count or the grandma pool changes; menus re-render every second or on force.

## 6. Art

All images come from `Interface\AddOns\MauCookie\Textures\<key>.tga` (`NS.Art(key)`), uncompressed 32-bit TGA written bottom-up with an 8-bit alpha descriptor. **The `Textures` folder is git-ignored and `build.ps1` does not pack it**: the images are the original Cookie Clicker's, copyrighted by Orteil / DashNet, used privately by the user and one friend who gets the folder by hand. The Claude Code auto-mode classifier blocked committing or zipping them once; do not try again. `tools/convert-art.ps1` builds the folder from the original `img/` files (downloaded from `https://orteil.dashnet.org/cookieclicker/img/<name>` into `cc-source/img` and `cc-download` next to `tools/`; 240 files were needed, see the script for the list) and writes `Art.lua`. Modes: `pad` (top-left in a power-of-two canvas, texcoords from `Art.lua`), `scale` / `scale256` (stretched, for tiles: milks, backgrounds, store tile), `square` (centred in a square so `SetRotation` works: the wrinklers), strips re-laid as grids (`santa` 4 columns, `dragon` 3, `brokenCookie`), and the icon sheet cut into four 1024 px tiles of 21 x 21 cells (`icons_<x>_<y>.tga`; `NS.SetIcon(tex, {col,row})` picks the tile and texcoords, `NS.IconString` makes the `|T...|t` escape for tooltips). The buildings sheet is padded to 256 x 2048 (`NS.SetBuildingIcon(tex, column, row)`). Missing textures show as empty squares; new files need a full client restart. 0.4.0's per-cell `icon_<c>_<r>.tga` and `building_<id>.tga` files are no longer used.

## 7. Guild board (`Comm.lua`)

Unchanged protocol from 0.2.0 (`S:` snapshot newest-timestamp-wins, `I:` inventory, `Q:` requests, jitter and suppression, one message per 0.25 s; see `../MauPeggle/CLAUDE.md` section 8 for the relay logic). The snapshot fields now come from `save.prestige`, `Game:AllTime()`, `save.earned`, `Game.cps`, `Game:BuildingsOwned()`, `Game:AchievementsOwned()`, `save.goldenClicks`, `save.resets`. The board is the Guild menu in the middle section.

## 8. How to verify

1. `node tools/check.js *.lua` from the addon folder: every file OK. Then `cd tools/headless && npm i fengari && node run.js`: the headless session (stubbed WoW API, see `tools/headless/README.md`) must end with `guarded errors: 0 step failures: 0`. It runs the whole core and every window code path with stub frames; it found the 0.5.0 load crash (a sort comparing a numeric tier with "fortune" in Index.lua), so run it after every change.
2. `/mck`: the three columns, the bakery name, the cookie wobbles on hover and click, +1 floats, Cursor and Grandma products, the rest "???". Buy a cursor: the store shows Reinforced index finger and Carpal tunnel prevention cream after one, Ambidextrous after ten. Buy a grandma: a Grandma row with a grandma sprite appears in the middle.
3. Close the window, wait, reopen: cookies kept coming. Log out and back in: no "away" cookies.
4. A golden cookie within 5-15 minutes with the window open; its note names the effect; buff icon with pie timer at the top right.
5. Stats: the listing, owned upgrade crates, the achievement grid with tooltips. Options: toggles work, Wipe asks twice. Info text. Guild board tabs.
6. Legacy: the tree preview with Legacy at the centre; with a trillion cookies all time, Ascend asks, then the tree is live, Legacy costs 1 chip, Reincarnate resets the run (starter buildings if owned).
7. A carried-over 0.4.0 save: the chat line about the migration, buildings and upgrades still owned, prestige recomputed.
